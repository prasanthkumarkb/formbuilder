# Laravel Form Builder

A low-code Journey/Form Builder package for Laravel.

## Features

- Screen Builder
- Section Builder
- Field Builder
- Drag & Drop Ordering
- JSON Preview
- Journey Publish
- Validation Support
- AJAX CRUD Operations

## Installation

```bash

composer require prasanth/form-builder

```

## Publish Assets

```bash
php artisan vendor:publish --tag=formbuilder-assets
```

## Publish Config

```bash
php artisan vendor:publish --tag=formbuilder-config
```

## Run Migrations

```bash
php artisan migrate
```

## Access Builder

```text
/admin/forms
```

## Requirements

- PHP 8.1+
- Laravel 10+
